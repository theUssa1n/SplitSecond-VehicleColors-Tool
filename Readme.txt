Split/Second VehicleColors.param - Usage Guide
This guide explains how to locate and use the VehicleColors.params file for Split/Second.
1. SSDC Version (Recommended)
-----------------------------
- File Location: "Main Game Folder"\Deferred\Vehicles
(Note) This version is highly recommended as it supports "Retail Unpacked" structure, allowing for easy content overrides and modding. You can easily use community-made mods and custom color palettes.
[IMPORTANT] Fixed File: The "fixed-vehiclecolors_for-ssdc" folder in this package contains a corrected params file. It fixes a specific bug where DLC vehicles could interfere with each other when applying new palettes. 
  If this is your first time using the tool, please replace your game's original file with this one before loading it into the tool to make your changes.

2. Steam Version
----------------
Currently not directly supported.
The Steam version uses packed ".ark" archives, unlike the SSDC version which is unpacked. This makes direct file manipulation impossible without extracting the archives first.
It is strongly suggested to use the SSDC version (available in the community server) to enable full modding support, community patches, and seamless use of this tool.

Enjoy!
