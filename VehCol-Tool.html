Usage Guide & Documentation

1. Getting Started & Offline Support

  • • File Upload: Click the "Upload File" area or drag your VehicleColors.params file directly into the tool.
  • • Fully Offline: This tool is now 100% offline-ready. All resources (fonts, icons, styles) are loaded locally from the resources/ folder.
  • • Vehicle Selection: Once uploaded, use the main dropdown to select a car. Use the Vehicle List icon for a searchable directory.
  • [Important] SSDC Fixed File: The fixed-vehiclecolors_for-ssdc/ folder contains a corrected VehicleColors.params. This fix prevents a known bug where DLC vehicle palettes could interfere with each other. If this is your first time using the tool, replace your game file with this one before loading it to make changes.

2. Understanding the Color Layers

Each color slot consists of three technical layers used by the game's engine:

  • — Paint: Acts as the base shading and tint layer.
  • — Lacquer: The primary visible body paint. This is your main color.
  • — Flake: A glossy, metallic layer that creates reflections and shine highlights.

Note: For a "flat" solid look, match the hex/RGB values across all three layers.

In-Game Swatch Logic:

The game uses the 'Swatch type' parameter (usually set to Paint) to display the color preview in menus. Whatever color value is assigned to that specific layer will be shown as the small square preview in the vehicle selection screen.

3. New Features

  • ★ Color Library: Found a perfect combo? Click "+ Library" on any slot to save it. Open the Library menu to apply your saved presets to any vehicle.
  • ★ Full Vehicle Copy/Paste: Use the Copy and Paste buttons in the bottom toolbar to transfer all color slots from one vehicle to another in a single click.
  • ★ Sync Logic (DLC): When editing DLC vehicles, the Sync feature ensures that hidden "Placeholder" models are updated simultaneously to prevent in-game rendering bugs.
  • ★ Smart Randomizer: Click the icon to generate harmonious color schemes based on color theory (Complementary, Analogous, etc.) to ensure a professional look.

4. Layout & Management

  • • Palette Size: Change the number of available color slots (1-9) per vehicle.
  • • Batch Max Size: Click to unlock all 9 slots for every vehicle in the file at once.
  • • Drag & Drop: Use the handle on any slot to reorder your colors.

5. Finalizing Your Changes

Click Save in the bottom toolbar. The tool will generate a perfectly formatted VehicleColors.params file. Replace the original file in your game's directory to see your new designs in action.
